# WMS — система адресного складського обліку (курсова робота)

Node.js (Express) + PostgreSQL. Реалізує схему БД з лабораторних 2-4 (OLTP + OLAP)
для системи складського обліку (WMS).

## Запуск

1. Встановити залежності: `npm install`
2. Створити базу `wms_kursova` і виконати `db/schema.sql`.
3. Скопіювати `.env.example` → `.env`, вказати `DATABASE_URL`.
4. Запустити: `npm start` (або `npm run dev`).

## Структура

- `db/schema.sql` — DDL і тестові дані (labs 2-3).
- `docs/adr/` — специфікація, ADR, ER-діаграма, тести обмежень.
- `docs/lab3/`, `docs/lab4/` — звіти та SQL-скрипти лабораторних.
- `src/server.js` — Express-сервер (CRUD, оприбуткування, переміщення/списання, звіти).
- `views/` — EJS-шаблони.

## Функціонал

- Довідники: товари, постачальники, комірки складу (CRUD).
- Накладні постачання: створення, позиції, оприбуткування, скасування, видалення.
- Залишки по комірках, журнал переміщень і списань.
- Аналітичні звіти (OLAP): агрегація, GROUP BY, HAVING, JOIN, підзапити,
  багатотаблична агрегація, віконні функції, товари нижче мінімуму.
- Контроль місткості комірок і наявності залишку на рівні застосунку (транзакції).
